# Todo

A small single-page todo app built with Next.js 15 (App Router) and React 19. You can add, complete, delete and clear todos, switch between a dark and light theme, and send feedback through a floating widget. All state lives in React memory with no backend, so refreshing the page clears everything.

## Quick start

```bash
npm install
npm run dev
```

Then open <http://localhost:3000>.
